\# IBM Bob Usage – AI Career Copilot



\## Project Overview



AI Career Copilot is an AI-powered career guidance platform that helps students and job seekers analyze their resumes, identify skill gaps, generate career roadmaps, assess job readiness, analyze GitHub profiles, and practice mock interviews.



\## How IBM Bob Was Used



IBM Bob was used throughout the development and refinement of the project.



\### 1. Project Analysis

IBM Bob was used to analyze the existing codebase, identify technical issues, and prioritize problems based on their impact.



\### 2. Development

IBM Bob assisted in implementing and improving:

\- FastAPI backend

\- React frontend

\- Resume analysis workflow

\- AI career recommendations

\- Skill-gap analysis

\- Career roadmaps

\- Job readiness analysis

\- GitHub analysis

\- AI mock interview functionality



\### 3. Bug Fixing

IBM Bob was used to identify and fix issues such as:

\- AI service integration errors

\- Resume data mapping issues

\- Missing role configurations

\- Authentication and JWT security improvements

\- File upload validation

\- GitHub API rate-limit handling



\### 4. Security Improvements

IBM Bob helped improve application security by:

\- Moving secrets to environment variables

\- Adding JWT token expiration

\- Validating uploaded PDF files

\- Limiting upload file size

\- Sanitizing uploaded filenames

\- Adding environment files to `.gitignore`



\### 5. Testing and Refinement

IBM Bob was used iteratively to review changes, troubleshoot errors, and verify that the implemented features worked correctly.



\## Technology Stack



\- React

\- Vite

\- FastAPI

\- Python

\- PostgreSQL

\- SQLAlchemy

\- Google Gemini API

\- GitHub API

\- JWT Authentication



\## Development Workflow



The development process followed an iterative workflow:



1\. Analyze the project

2\. Identify issues

3\. Plan improvements

4\. Implement changes

5\. Test the implementation

6\. Fix errors

7\. Refine the project

8\. Prepare the final submission



IBM Bob was used as an AI development assistant during these stages.
